Install and use

From GitHub clone to first run in a few minutes.

  1. 1 Download the repo. Clone or download WriterDrip from GitHub.
  2. 2 Load the extension. Open chrome://extensions, enable Developer mode, then click Load unpacked and select the folder that contains manifest.json.
  3. 3 Open your Google Doc. Click inside the document body so WriterDrip can attach to the active editor.
  4. 4 Paste, choose, and start. Paste your draft, choose a duration and correction intensity, then start the drip. Keep your browser open, keep the original Google Doc tab open, and keep your computer awake while the run is active. If you need to stop for the day, pause it and resume later from the same Google Doc.

FAQ

What people usually want to know first.

Does it just type straight through?

No. WriterDrip is built around a correction engine that can introduce and fix typos, spacing slips, punctuation mistakes, repeated words, and delayed repairs while keeping the final text aligned to the draft.

Does WriterDrip use my Google account?

No. WriterDrip works against the Google Doc already open in your browser and does not require OAuth.

Does it keep running if I switch tabs?

Yes. WriterDrip stays bound to the original Google Doc tab while you use other tabs, as long as your browser and computer stay on.

Does my laptop have to stay on?

While a drip is actively running, yes. WriterDrip runs locally in your browser, so your computer must stay awake and the original Google Doc tab must stay open. If you need a break, pause the run and resume later from the same Google Doc.

Is WriterDrip free?

Yes. The project is MIT-licensed, open source, and available from the public GitHub repository.

Does it control Google Docs version history?

No. WriterDrip types into the live editor, but Google still controls how revision history is grouped and displayed.
